## 설치

1. 위 버튼을 눌러 `MyLauncher-Web-Setup.exe`를 받아 실행해요.
2. Windows 파란 경고 창이 뜨면 **추가 정보 → 실행**을 눌러요.
3. 설치가 끝나면 런처가 켜져요. 마이크로소프트 계정으로 로그인하고 **플레이**를 누르면 게임과 모드를 알아서 받아요.

## 업데이트

이미 설치했다면 따로 받을 필요가 없어요. **런처를 껐다가 다시 켜면** 새 버전을 확인해서 자동으로 설치해요.

## 릴리스 페이지의 다른 파일들

[릴리스 페이지](https://github.com/kindeo8989/mylauncher-releases/releases)에는 파일이 여러 개 있어요. **받을 것은 `MyLauncher-Web-Setup.exe` 하나뿐**이에요.

| 파일 | 하는 일 |
|---|---|
| `MyLauncher-Web-Setup.exe` | 설치 파일 (이것만 받으면 돼요) |
| `latest.yml` | 런처가 새 버전을 확인할 때 써요 |
| `MyLauncher-Web-Setup.exe.blockmap` | 업데이트할 때 바뀐 부분만 받게 해 줘요 |
| `MyLauncher-Web-Setup.exe.sig` | 업데이트 파일이 진짜인지 런처가 확인할 때 써요 |
| `changelog.json` | 런처의 패치노트 화면에 보여 줄 내용이에요 |
| Source code (zip / tar.gz) | GitHub가 자동으로 붙이는 파일이에요. 받지 않아도 돼요 |
